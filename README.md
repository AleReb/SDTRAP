# SDTRAP-EdgeSD

Project for recovering images from conventional trail cameras using a shared SD bus, ESP32-S3 edge processing, and later Wi-Fi/LTE transmission.

## Rules

- Arduino IDE / current Arduino-ESP32 core.
- No PlatformIO unless explicitly requested.
- Firmware lives under `software/`.
- Hardware work lives under `hardware/`.
- FYSETC repositories are technical references only.
